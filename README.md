# 🚗 Toyota Car Showcase Website

A responsive and user-friendly website that showcases different Toyota cars along with their specifications, comfort features, and engine details.

---

## 🌟 Features

* **Car Listings**: Includes models like Toyota Glanza, Yaris, Camry, Fortuner, Land Cruiser, and more.
* **Detailed Specifications**: Each car page contains engine details, mileage, and performance information.
* **Comfort & Features Section**: Highlights key features such as seating, safety, and technology options.
* **Responsive Design**: Fully responsive layout, optimized for desktops only.
* **Clean UI/UX**: Simple and modern design for easy navigation.
* **Login Page**: To be a member of our company.

---

## 🛠️ Tech Stack

* **Frontend**: HTML, CSS.
* **Responsive Design**: Media queries and modern layout techniques
